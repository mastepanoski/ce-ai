# Product Requirements Document: Release v0.5.0 Roadmap Features

**Date**: 2026-08-21  
**Target Release**: `ce-ai` v0.5.0  

---

## 1. Executive Summary

Release v0.5.0 completes the core ecosystem roadmap for `ce-ai` by delivering three critical capabilities:
1. **Scope-Aware Installation (Issue #7)**: Allows installing plugins/skills either globally (`~/.config/` / `~/.claude.json`) or scoped locally to the current git workspace (`./.opencode/`, `./.cursorrules`, `./.claude/`).
2. **Companion Tools & Sidecars Manager (Issue #9)**: Native status detection, installation, and MCP config wire-up for AI developer companion tools (`Engram`, `CodeGraph`, `Context7`, `RTK`).
3. **Workflow FSM & Progress Recovery (Issue #10)**: State machine tracking across the 7 development stages (`Ideation` ➔ `OpenSpec` ➔ `Plan` ➔ `TDD/Work` ➔ `Verify` ➔ `Compound` ➔ `Ship`), enabling progress checkpointing and context recovery after agent compactions.

---

## 2. Feature Specifications

### Feature A: Workspace vs. Global Scope Installation (Issue #7)
- **CLI Commands**:
  - `ce-ai install --scope global` (Default, user-wide installation)
  - `ce-ai install --scope workspace` (Repository-scoped installation)
- **Behavior**:
  - Automatically resolves git repository root using `git rev-parse --show-toplevel`.
  - In workspace scope, installs managed skills into `./.opencode/skills/` or `./.claude/skills/` and updates local config.
  - Records scope choice in `install-manifest.json` and `state.json`.

### Feature B: Companion Tools & Sidecars Manager (Issue #9)
- **CLI Commands**:
  - `ce-ai tools status` (Lists status of Engram, CodeGraph, Context7, RTK)
  - `ce-ai tools install <engram|codegraph|context7|rtk>`
  - `ce-ai doctor` (Includes companion tools version & PATH diagnostics)
- **Behavior**:
  - Probes system `PATH` binaries and harness MCP configurations (`mcp_servers` in `opencode.json`, `~/.config/claude/`, etc.).
  - Wire-up detected or installed MCP servers directly into target harness configs (`opencode.json`, `.cursorrules`, etc.).

### Feature C: Workflow FSM & Agent Progress Recovery (Issue #10)
- **CLI Commands**:
  - `ce-ai workflow status` (Displays current 7-stage phase, active subtask, and OpenSpec checklist state)
  - `ce-ai workflow checkpoint --task "4.2 TDD" --phase "Stage 4: TDD"` (Saves checkpoint to state)
  - `ce-ai workflow resume` (Restores context using Engram memory and OpenSpec state)
- **Behavior**:
  - Tracks 7-stage FSM state transitions.
  - Queries Engram persistent memory (`mem_context`, `mem_search`) and session summaries to re-hydrate context post-compaction.
