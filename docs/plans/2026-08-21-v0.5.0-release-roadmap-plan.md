## 1. Unit Breakdown

### Unit 1: Workspace Scope Installation (Issue #7)
- Update `src/commands/install.rs` to parse `--scope <workspace|global>`.
- If `scope == workspace`, execute `git rev-parse --show-toplevel` to locate repo root, installing managed files into `./.opencode/` or `./.claude/` locally.

### Unit 2: Companion Tools Manager (Issue #9)
- Create `src/commands/tools.rs` with `tools status` and `tools install <engram|codegraph|context7|rtk>`.
- Probe system `PATH` and harness MCP configurations.

### Unit 3: Workflow FSM & Progress Recovery (Issue #10)
- Create `src/commands/workflow.rs` with `workflow status`, `checkpoint`, and `resume`.
- Save state transitions to `state.json` under `workflow_checkpoint`.

### Unit 4: Version Bump to v0.5.0 (`Cargo.toml` & `CHANGELOG.md`)
- Update version in `Cargo.toml` to `0.5.0`.
- Document new features in `CHANGELOG.md`.
